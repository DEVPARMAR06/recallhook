---
description: Open the recallhook memory dashboard in your browser
allowed-tools: Bash(recallhook ui:*)
---

Run `recallhook ui` to open the dashboard (http://127.0.0.1:8788/_recallhook/ui), then tell the user it was opened. If the command is not found, tell the user to run `pipx install recallhook` and then `recallhook init --no-hook`. Do not run any other commands.
